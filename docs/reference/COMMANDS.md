# 命令与 Ex 历史

> `:` 开头的命令历史比想象中长。这一篇按用途列常用的。

## 文件

| 命令 | 作用 |
|---|---|
| `:e 文件` | 打开 |
| `:e!` | 重载，丢弃修改 |
| `:w` | 保存 |
| `:w 文件` | 另存 |
| `:w!` | 强制保存 |
| `:wq` / `:x` | 保存退出 |
| `:q` / `:q!` | 退出 / 强制退出 |
| `:wa` | 保存所有 |
| `:qa` / `:qa!` | 退出所有 |
| `:saveas 文件` | 另存为新文件并切换过去 |
| `:r 文件` | 把文件内容读进来 |
| `:r !命令` | 把命令输出读进来 |

**只读文件用 sudo 保存**：

```vim
:w !sudo tee %
```

## 缓冲区

| 命令 | 作用 |
|---|---|
| `:ls` | 列出 buffer |
| `:b 名字` / `:b 编号` | 切换 |
| `:bn` / `:bp` | 下一个 / 上一个 |
| `:bd` | 关闭 buffer |
| `:bufdo 命令` | 对每个 buffer 执行 |
| `:ball` | 所有 buffer 各开一个窗口 |

## 窗口与 tab

| 命令 | 作用 |
|---|---|
| `:sp` | 水平分割 |
| `:new` | 水平分屏并打开新的空 buffer |
| `:vs` | 垂直分割 |
| `:resize 20` | 改高度 |
| `:vertical resize 80` | 改宽度 |
| `:windo 命令` | 对每个窗口执行 |
| `:tabnew` | 新 tab |
| `:tabclose` | 关 tab |
| `:tabonly` | 只留当前 tab |

## 搜索与替换

| 命令 | 作用 |
|---|---|
| `:s/旧/新/g` | 当前行替换 |
| `:%s/旧/新/gc` | 全文替换，逐个确认 |
| `:s/旧/新/g` | 可视选区替换 |
| `:noh` | 清除搜索高亮 |
| `:vimgrep /模式/ 文件` | 搜到 quickfix |
| `:grep 模式` | 调用外部 grep |
| `:copen` / `:cclose` | 开关 quickfix |
| `:lopen` | location list |

## 全局命令

| 命令 | 作用 |
|---|---|
| `:g/模式/命令` | 对匹配行执行 |
| `:g!/模式/命令` | 对不匹配行执行（= `:v`） |
| `:g/模式/d` | 删匹配行 |
| `:g/模式/t$` | 复制匹配行到末尾 |
| `:g/模式/normal! 操作` | 对匹配行执行普通模式操作 |

## 设置

| 命令 | 作用 |
|---|---|
| `:set opt` / `:set noopt` | 开 / 关布尔选项 |
| `:set opt=值` | 设值 |
| `:set opt?` | 查看 |
| `:verbose set opt?` | 查看 + 来源 |
| `:set opt&` | 恢复默认 |
| `:setlocal` / `:setglobal` | 指定作用域 |

## 键位与命令查询

| 命令 | 作用 |
|---|---|
| `:map` | 列出所有普通模式映射 |
| `:nmap` / `:imap` / `:xmap` | 按模式列 |
| `:verbose nmap 键` | 映射 + 定义来源 |
| `:command` | 列出用户命令 |
| `:autocmd` | 列出自动命令 |
| `:verbose autocmd 事件` | 带来源 |

## 当前配置的重载入口

`:ConfigReload` 或 `<leader>uR` 打开定向重载菜单。
可用 `:ConfigReload keymaps`、`:ConfigReload files`、`:ConfigReload statusline`
分别重载快捷键、文件操作和状态栏；`:ConfigReload all` 重载这三个范围。
插件安装、LSP 与启动设置的变更仍需重启。详见
[新建文件、文件条与配置重载](../guides/FILES-TABS-AND-RELOAD.md)。

## 会话

| 命令 | 作用 |
|---|---|
| `:mksession 文件` | 保存会话 |
| `:source 文件` | 载入会话/脚本 |
| `:wshada` / `:rshada` | 保存/读回状态 |

## 撤销

| 命令 | 作用 |
|---|---|
| `:undo` | 撤销 |
| `:redo` | 重做 |
| `:earlier 10m` | 回到 10 分钟前 |
| `:later 10m` | 前进 10 分钟 |
| `:undolist` | 列出撤销分支 |

`:earlier` / `:later` 按时间跳转，比连按 `u` 快。

## 外部命令

| 命令 | 作用 |
|---|---|
| `:!命令` | 执行 shell 命令 |
| `:r !命令` | 读命令输出 |
| `:w !命令` | 把内容送给命令 |
| `:!命令 %` | 对当前文件执行（`%` 是文件名） |
| `:%!命令` | 整个文件过一遍命令 |

**格式化整个文件**：`:%!jq .`（JSON）、`:%!python -m json.tool`。

## 帮助

| 命令 | 作用 |
|---|---|
| `:help` | 帮助首页 |
| `:help 主题` | 查主题 |
| `:help :命令` | 查命令 |
| `:help '选项'` | 查选项 |
| `:helpgrep 词` | 全文搜帮助 |
| `:checkhealth` | 健康检查 |

## 补全命令行

输入命令时按 `Tab`（或 `Ctrl-d` 看列表）：文件名、选项、命令都能补全。

## 命令行编辑

| 键 | 作用 |
|---|---|
| `Ctrl-b` / `Ctrl-e` | 跳到开头 / 结尾 |
| `Ctrl-w` | 删前一个词 |
| `Ctrl-u` | 删整行 |
| `Ctrl-r` | 插入寄存器内容 |
| `Ctrl-f` | 打开历史编辑窗口 |
| `q:` | 打开历史窗口（可编辑） |

`q:` 在写复杂替换时好用——像编辑普通文本一样改命令。
