# 02 光标移动：手指别离开主键区

> 这一篇讲怎么在文件里移动。移动是编辑里最频繁的动作，值得先练熟。

## 最小的一套

四个键，右手在正常打字位置就能按到：

| 键 | 方向 |
|---|---|
| `h` | 左 |
| `j` | 下 |
| `k` | 上 |
| `l` | 右 |

`j` 和 `k` 挨着，`h` `l` 在最外侧。刚开始会按错，练两天就顺了。

## 按词跳，不是按字符

按字符挪太慢。一个词一个词跳：

| 键 | 作用 |
|---|---|
| `w` | 下一个词的词首 |
| `b` | 上一个词的词首 |
| `e` | 当前/下一个词的词尾 |
| `W` `B` `E` | 同上，但把标点也算进词里 |

`w` 是 word，`b` 是 back，`e` 是 end。大小写的差别：小写按「单词」跳（`foo-bar` 算三个词），大写按「空白分隔」跳（`foo-bar` 算一个）。

改代码时小写更常用，因为 `getUserName` 这种驼峰能分开跳。

## 按行跳

| 键 | 作用 |
|---|---|
| `0` | 行首（第 0 列） |
| `^` | 行首第一个非空字符 |
| `$` | 行尾 |
| `gg` | 文件第一行 |
| `G` | 文件最后一行 |
| `42G` 或 `:42` | 跳到第 42 行 |

`0` 和 `^` 的差别在有缩进的代码里很明显：`0` 到最左边，`^` 到代码的第一个字符。日常改代码基本用 `^`。

## 屏幕内快速跳

这一屏里要跳到某个位置：

| 键 | 作用 |
|---|---|
| `H` | 屏幕顶部 |
| `M` | 屏幕中间 |
| `L` | 屏幕底部 |
| `Ctrl-d` | 向下半屏 |
| `Ctrl-u` | 向上半屏 |
| `Ctrl-f` | 向下一页 |
| `Ctrl-b` | 向上一页 |

## 跳过去还能跳回来

这是新手最容易忽略、但极其重要的一组：

| 键 | 作用 |
|---|---|
| `Ctrl-o` | 回到上一个位置 |
| `Ctrl-i` | 前进到下一个位置 |

用 `G` 跳到文件末尾，改了两行，`Ctrl-o` 就回到原处。这比记行号好用得多。

**这一组配合搜索和跳转定义使用，是效率的关键。**

## 带计数前缀

几乎所有移动都能加数字：

```
5j      往下 5 行
3w      往后 3 个词
10G     第 10 行
```

不用一次记准。先按 `5j`，发现不对再 `2j` 补一点。

## 段落和括号

改代码时这两个很有用：

| 键 | 作用 |
|---|---|
| `{` `}` | 上一个/下一个空行（段落边界） |
| `%` | 跳到配对的括号 |
| `(` `)` | 上一个/下一个句子 |

在函数之间跳用 `{` `}`，比数行快。

## 练习

打开一个稍长的文件（比如这份配置的 `README.md`）：

1. 用 `j` `k` 上下移动 10 行
2. `w` 往后跳 5 个词，`b` 退回来
3. `G` 到文件末尾，`Ctrl-o` 回来
4. `5j` 往下 5 行，`3k` 往上 3 行
5. `$` 到行尾，`^` 到行首第一个字符

**验收**：能不看键盘完成上面五步。

## 这一篇不讲什么

原书那个年代还讲 `H` `M` `L` 配 `z` 命令调整屏幕位置，现在用得少，需要时 `:help scroll-cursor`。
