# 04 基本编辑：删、改、撤销

> 移动练完，这一篇讲真正改动文本。Vim 的编辑命令有个统一规律，抓住它就不用死记。

## 进入插入模式

| 键 | 从哪里开始插入 |
|---|---|
| `i` | 光标**前** |
| `a` | 光标**后**（append） |
| `I` | 行首第一个非空字符前 |
| `A` | 行尾 |
| `o` | 下面新开一行 |
| `O` | 上面新开一行 |

`i` 和 `a` 是最常用的两个。`A` 在行尾追加，改配置时很顺手。

打完字按 `Esc` 回到普通模式。**养成习惯：每次输入完立刻 `Esc`。**

## 删除

| 键 | 删什么 |
|---|---|
| `x` | 光标下这个字符 |
| `X` | 光标前这个字符 |
| `dw` | 一个词 |
| `dd` | 一整行 |
| `D` | 从光标到行尾 |
| `d$` | 同上 |
| `d0` | 从行首到光标 |

`dd` 最快。想删三行？`3dd`。

**注意**：`dd` 删掉的内容进了寄存器，可以用 `p` 粘回来。它不是真的销毁，是「剪切」。

## 这里的规律：命令 + 范围

看到 `dw` 和 `dd` 应该能发现：`d` 是「删除」这个动作，后面跟「删多少」。

```
d  +  w  = 删到下一个词
d  +  d  = 删一整行（d 重复表示整行）
d  +  $  = 删到行尾
```

这个「操作符 + 动作」的语法是 Vim 的核心。**下一篇之后所有编辑命令都按这个规律**，[12 操作符与动作语法](12-operator-grammar.html)会专门讲透。

现在只要记住：`d` 是删除，后面接什么就删什么。

## 修改

| 键 | 作用 |
|---|---|
| `r` | 替换一个字符（不进入插入模式） |
| `R` | 进入替换模式，一直覆盖 |
| `cw` | 改一个词（删掉并进入插入模式） |
| `cc` | 改一整行 |
| `C` | 改到行尾 |
| `~` | 切换大小写 |

`cw` 和 `cc` 是 `c`（change）+ 范围。它比「先删再插」少一步。

`C` 在改配置值时特别常用：光标放在值前面，`C`，输入新值，`Esc`。

## 撤销与重做

| 键 | 作用 |
|---|---|
| `u` | 撤销 |
| `Ctrl-r` | 重做 |
| `U` | 撤销整行的所有修改 |

`u` 可以连按多次，一直往回退。

**Vim 的撤销是树状的**：撤销之后如果又做了新改动，原来的「未来」不会被丢掉，还能通过 `g-` / `g+` 在时间线上移动。日常用 `u` / `Ctrl-r` 就够。

## 重复上一个修改

| 键 | 作用 |
|---|---|
| `.` | 重复上一次修改 |

这是 Vim 最值钱的一个键。

比如要删 5 处相同的词：光标到第一处，`dw`，然后 `j.j.j.` 一路删下去。

改一处，`. ` 重放。改文件时这个动作能省掉大量重复劳动。

## 缩进

| 键 | 作用 |
|---|---|
| `>>` | 当前行右缩进 |
| `<<` | 当前行左缩进 |
| `3>>` | 三行右缩进 |
| `=` | 自动缩进（可视模式选中后按） |

`gg=G` 是「整个文件重新缩进」，收拾粘贴进来的乱代码时很有用。

## 练习

找一段可以随便改的文字：

1. 按 `x` 删三个字符，`u` 撤销
2. `dd` 删一行，`p` 粘回来
3. `cw` 改一个词，`Esc` 退出
4. 再按一次 `cw` 改下一个词，然后 `.` 重复
5. `>>` 缩进，`<<` 退回来
6. `gg=G` 重新缩进整个文件，`u` 撤销

**验收**：能说清 `dd` 和 `dw` 的差别，能用 `.` 重复修改。
