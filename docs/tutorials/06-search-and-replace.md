# 06 查找与替换

> 在一个几百行的文件里找东西，和把找到的东西全部改掉。这两件事占了编辑工作的一大半。

## 查找

| 命令 | 作用 |
|---|---|
| `/关键字` | 往下找 |
| `?关键字` | 往上找 |
| `n` | 找下一个（沿当前方向） |
| `N` | 找上一个 |
| `*` | 找光标下的词 |
| `#` | 同上，反方向 |

`*` 是最顺手的：光标停在一个词上，按 `*`，全文所有这个词都高亮，`n` 一路跳过去。

### 搜索的几个开关

| 命令 | 作用 |
|---|---|
| `:set hlsearch` | 高亮所有匹配（默认开） |
| `:set incsearch` | 边输入边跳 |
| `:set ignorecase` | 忽略大小写 |
| `:set smartcase` | 有大写时区分，全小写时忽略 |
| `:nohlsearch` 或 `:noh` | 关掉当前高亮 |

`smartcase` 值得开：搜 `foo` 会匹配 `Foo`，搜 `Foo` 就只匹配 `Foo`。这份配置已经开了。

我们的配置里 `<Esc>` 会顺便清掉搜索高亮，不用手动 `:noh`。

## 跳过去的偏移

找到之后往往还要挪一点：

| 命令 | 作用 |
|---|---|
| `/foo/e` | 跳到匹配的**末尾** |
| `/foo/+2` | 匹配所在行的下 2 行 |
| `/foo/b+1` | 匹配开头后 1 个字符 |

写替换脚本时这些很有用。

## 替换

基本语法：

```vim
:s/旧/新/        当前行第一个
:s/旧/新/g       当前行所有
:%s/旧/新/g      整个文件
:%s/旧/新/gc     整个文件，每个都问一次
```

| 部分 | 含义 |
|---|---|
| `%` | 整个文件（`1,10` 表示 1–10 行） |
| `s` | substitute |
| `g` | 一行内的所有匹配（不加只换第一个） |
| `c` | 每个替换前确认 |

**`c` 是安全阀**。不确定会不会误改时，先加 `c` 逐个确认，看几个就知道规律对不对。

### 确认时按什么

`:s/.../.../gc` 每次停下来问：

| 键 | 作用 |
|---|---|
| `y` | 换这一处 |
| `n` | 跳过 |
| `a` | 全部换掉，不再问 |
| `q` | 停止 |
| `l` | 换这一处然后停止 |

## 在可视范围里替换

先选中几行，再替换：

```
V 选中几行
:s/旧/新/g       只作用于选中的行
```

命令行会自动补上 `'<,'>` 这个范围。

## 替换里用捕获组

```vim
:s/\(\w\+\)\.cob/\1.cbl/
```

`\(` `\)` 分组，`\1` 引用。Neovim 里可以写更现代的形式，但要加 `\v`：

```vim
:%s/\v(\w+)\.cob/\1.cbl/g
```

`\v` 是 `very magic`，之后正则就是常见写法（不需要到处加反斜杠）。

## 什么时候别用 `:s`

`:%s` 只作用于**当前文件**。要改整个项目里所有文件：

- 用 `<leader>sr`（grug-far），它先显示匹配数，你确认后再落盘
- 见 [插件手册：grug-far](../plugins/grug-far.nvim.html)

**批量改动前一定先看匹配数。** 数字不对说明模式写错了。

## 练习

打开一个较大的文本文件：

1. `/功能` 找一处，`n` 连跳三次
2. 光标停在一个词上按 `*`，确认全文高亮，`n` `N` 来回跳
3. `:set noh` 清掉高亮
4. `:%s/的/之/gc`，逐个确认几处后按 `q` 停下
5. `u` 撤销
6. 选中三行，`:'<,'>s/。//g` 去掉句号

**验收**：能用 `*` + `n` 快速定位，能用 `c` 标志安全替换。
