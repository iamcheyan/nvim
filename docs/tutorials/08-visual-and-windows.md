# 08 可视模式与窗口

> 可视模式是「先选中再操作」。它不如操作符+动作快，但看得见，适合不确定范围的时候。

## 三种可视模式

| 键 | 模式 | 选中什么 |
|---|---|---|
| `v` | 字符可视 | 从起点到终点的字符 |
| `V` | 行可视 | 整行 |
| `Ctrl-v` | 块可视 | 矩形区域 |

**注意**：这份配置把 `Ctrl-v` 给了智能粘贴，所以块可视要用 `Ctrl-q`。这是有意的取舍，见 [插件手册：smart-paste](../plugins/smart-paste.html)。

## 选中之后能做什么

选中一块，然后按操作符：

| 键 | 作用 |
|---|---|
| `d` | 删除 |
| `y` | 复制 |
| `c` | 删除并进入插入模式 |
| `>` / `<` | 缩进 / 反缩进 |
| `=` | 自动缩进 |
| `p` | 用寄存器内容替换选区 |
| `~` | 切换大小写 |
| `:` | 对选区执行命令行命令 |

`:` 那个很实用：`V` 选中五行，`:s/旧/新/g` 只替换这五行。

## 选中范围的扩展

| 键 | 作用 |
|---|---|
| `o` | 跳到选区另一端（继续调整） |
| `aw` | 选中一个词 |
| `ip` | 选中整个段落 |
| `i(` / `a(` | 括号内 / 含括号 |

`vip` 是「选中当前段落」，改一整段文字时很快。

## 块可视的用途

`Ctrl-q` 进入块模式后，可以：

**给多行加同样的前缀**

```
Ctrl-q 3j    选中下面 3 行的第 1 列
I            进入插入模式
输入 #       只有第一行显示，但其它行会同步
Esc          所有行都加上 #
```

**删掉每行开头的固定字符**

```
Ctrl-q 3j 4l    选中 4 行 × 4 列
d               整块删掉
```

这是「按列编辑」，纯文本处理时很有用。

## 重新选中上次的范围

| 键 | 作用 |
|---|---|
| `gv` | 重新选中上一次的范围 |

改完发现还要再改一次，`gv` 不用重新拉选区。

## 窗口操作补充

上一篇讲了基本的。这里几个高频的：

| 命令 | 作用 |
|---|---|
| `Ctrl-w` `s` | 水平分割（= `:sp`） |
| `Ctrl-w` `v` | 垂直分割（= `:vs`） |
| `Ctrl-w` `r` | 交换两个窗口的位置 |
| `Ctrl-w` `x` | 同上 |
| `Ctrl-w` `T` | 把当前窗口变成独立 tab |
| `Ctrl-w` `_` | 最大化当前窗口高度 |
| `Ctrl-w` `\|` | 最大化当前窗口宽度 |

`Ctrl-w _` 和 `Ctrl-w |` 在分屏看代码时很有用：临时把当前窗口撑满，看完再 `Ctrl-w =` 恢复。

## 窗口大小的精确调整

| 命令 | 作用 |
|---|---|
| `:resize 20` | 高度改成 20 行 |
| `:vertical resize 80` | 宽度改成 80 列 |
| `Ctrl-w 5+` | 高度加 5 |
| `Ctrl-w 5-` | 高度减 5 |

## 练习

1. 打开一个文件，`V` 选中三行，`>` 缩进，`u` 撤销
2. `vip` 选中整个段落，`y` 复制，`G` `p` 粘到末尾
3. `Ctrl-q` 选中三行第 1 列，`I` 输入 `# `，`Esc`，确认三行都加上了
4. `gv` 重新选中，`d` 删掉，`u` 撤销
5. `:vs` 分屏，`Ctrl-w _` 撑满，`:vertical resize 80` 调宽度
6. `Ctrl-w =` 恢复均分

**验收**：能用块可视给多行加同样前缀，能说清 `Ctrl-v` 和 `Ctrl-q` 在这份配置里的区别。

## 关于「可视化选择」的一个建议

熟练之后你会发现，很多操作用「操作符 + 动作」更快——`di(` 比「`v` 选中括号内再 `d`」少按一次，而且不用确认边界。

可视模式的价值在于**看得见**。不熟的时候用它，熟了自然会转向更短的形式。
