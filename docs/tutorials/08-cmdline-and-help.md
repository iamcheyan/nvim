# 08 命令行与帮助

> Vim 的救助系统是最完整的。学会查帮助，比背下所有按键有用。

## 命令行模式

按 `:` 进入。输入命令，`Enter` 执行，`Esc` 取消。

命令行里可以用方向键和 `Ctrl-p` / `Ctrl-n` 翻历史。

## 常用的几类命令

### 文件与保存

```vim
:w         保存
:q         退出
:wq        保存并退出
:e 文件     打开
```

### 搜索替换

```vim
:s/旧/新/g
:%s/旧/新/gc
:noh       清掉搜索高亮
```

### 设置选项

```vim
:set number        显示行号
:set nonumber      关掉
:set number?       查看当前值
```

详见 [09 选项与配置](09-options.html)。

### 执行外部命令

```vim
:!ls          执行 shell 命令
:!git status
:r !date      把命令输出读进文件
```

`:!` 是「去外面跑个命令」，跑完回 Vim。

**把命令结果插进文件**用 `:r !`：`:r !ls` 会把目录列表插到光标位置。

### 对多个文件执行

```vim
:argdo %s/旧/新/ge | update      对参数列表里每个文件替换
:bufdo %s/旧/新/ge | update      对每个 buffer 替换
:windo set number                对每个窗口设置
```

`:bufdo` 是批处理多个文件的利器。但**记得加 `| update`**，否则改动只留在内存里。

## 行号与范围

命令前面可以加范围：

| 写法 | 含义 |
|---|---|
| `:5` | 跳到第 5 行 |
| `:5,10d` | 删 5–10 行 |
| `:%s/.../.../` | 整个文件 |
| `:'<,'>s/.../.../` | 可视选区 |
| `:.,+3d` | 当前行往下 3 行 |
| `:$-1` | 倒数第二行 |

## 帮助系统

这是最该先学会的东西。

| 命令 | 作用 |
|---|---|
| `:help` | 打开帮助首页 |
| `:help 主题` | 查具体主题 |
| `:help :w` | 查 `:w` 命令 |
| `:help 'number'` | 查选项（带引号） |
| `:help i_CTRL-R` | 查插入模式下的 `Ctrl-r` |
| `Ctrl-]` | 在帮助里跳到链接 |
| `Ctrl-o` | 跳回来 |

### 主题名的前缀约定

| 前缀 | 查什么 | 例子 |
|---|---|---|
| `:` | 命令行命令 | `:help :s` |
| `'` | 选项 | `:help 'hlsearch'` |
| 无 | 普通模式按键 | `:help dd` |
| `i_` | 插入模式 | `:help i_CTRL-W` |
| `v_` | 可视模式 | `:help v_o` |
| `c_` | 命令行模式 | `:help c_CTRL-R` |

知道这个规律，`Ctrl-]` 能带你走完整个帮助系统。

### 用 picker 查帮助

这份配置里 `<leader>fh` 打开帮助搜索器，输入关键词就行，比记主题名快。

## 不知道自己按了什么

| 命令 | 作用 |
|---|---|
| `:verbose nmap <键>` | 这个键映射到哪、谁定义的 |
| `:map` | 列出所有普通模式映射 |
| `:map <leader>` | 列出 leader 开头的 |
| `:command` | 列出所有用户命令 |

`:verbose` 是关键——它告诉你**定义来自哪个文件**。文档说 `<leader>gd` 是这个功能，实际却是另一个，用这个能查出来。

## 命令历史与编辑

| 键 | 作用 |
|---|---|
| `q:` | 打开命令行历史窗口（可编辑后执行） |
| `Ctrl-f` | 在命令行里打开历史编辑 |
| `q/` | 搜索历史窗口 |

`q:` 在写长替换命令时很有用——可以像编辑普通文本一样修。

## 重复上一次命令行

```
@:
```

执行刚执行过的 Ex 命令。改配置调参数时方便。

## 练习

1. `:help` 打开帮助，随便找个主题，`Ctrl-]` 跳进去，`Ctrl-o` 回来
2. `:help 'hlsearch'` 查一个选项
3. `:verbose nmap <leader>gd` 看它定义在哪
4. `:!git log --oneline -3` 跑个外部命令
5. 光标放到文件开头，`:r !date` 把时间插进去
6. `q:` 打开历史，看看刚才的命令

**验收**：能用 `:help` 和 `:verbose nmap` 自己解决「这个键干什么」的问题。
