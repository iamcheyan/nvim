# 01 起步：先把观念摆正

> 这一篇不教按键。先说清楚 Vim 到底在干什么，后面才不会一直用错。

## 你可能已经踩过这个坑

大多数人第一次打开 Vim，想输入几个字，结果屏幕上出现了 `i`、`a`、`x` 之类的字符，或者文件直接乱了。

然后按 `Esc`，再按 `:`、`q`、`!` 才勉强退出来。整个过程像在猜密码。

这不是你笨。是 Vim 的操作模型和别的编辑器**根本不一样**，而没人先告诉你这一点。

## 核心差别：Vim 有两种状态

别的编辑器，你选中一段文字，然后打字，文字被替换。**只有一种状态**。

Vim 有**模式**：

| 模式 | 你在干什么 | 怎么进去 |
|---|---|---|
| 普通模式 | 下达命令（移动、删除、复制） | 按 `Esc` |
| 插入模式 | 打字 | `i`、`a`、`o` |
| 可视模式 | 先选中一块区域 | `v`、`V`、`Ctrl-v` |
| 命令行模式 | 执行 `:` 开头的命令 | `:` |

**打开文件时你在普通模式**。这时候按键不是输入文字，是下达命令。

这就是那个困惑的来源：你以为在打字，其实在按命令。

## 为什么这么设计

因为**下达命令比打字频繁得多**。

写一篇文章，打字占大部分时间。但改代码不是——你在读、在跳、在删、在挪。这些动作如果每次都要「按住方向键移动光标」「选中」「删除」，消耗很大。

Vim 把命令做成单个按键：`dw` 删除一个词，`3j` 往下三行，`ci"` 改掉引号里的内容。手指不离主键区。

代价是**要记**。好处是记住之后，编辑动作变成肌肉记忆，不用想。

## 三个必须先建立的习惯

**1. 不知道现在是什么模式时，按 `Esc`**

`Esc` 永远回到普通模式。按多次也无害。这能解决大部分「怎么打字不对劲」的问题。

**2. 从普通模式进入插入模式，用 `i`**

不要用方向键移动。先用 `h`/`j`/`k`/`l` 或词移动站到位置，再 `i` 开始打字。

**3. 想退出，先回普通模式再 `:q`**

`:q` 退出，`:q!` 强制退出（丢弃修改），`:wq` 保存并退出。

## 关于这份教程

这是「从零学」系列，一共 14 篇。前 10 篇覆盖一个编辑者需要的全部基础动作，后 4 篇讲按键背后的语法——那是新手真正卡住的第二层。

它参考了 Edward Lee 在 2000 年写的《大家來學VIM》的章节结构，但内容按今天的 Neovim 重写。原书里讲的 elvis、nvi、vile 这些编辑器已经没人用了，`set` 的写法也变了，所以不照搬。

**建议的读法**：先读 01–05，够你日常改文件。剩下的按需查。

## 下一步

先别急着记按键。打开一个随便的文本文件，练会这四件事：

1. 按 `i` 进入插入模式，打几个字
2. 按 `Esc` 回到普通模式
3. 按 `h` `j` `k` `l` 移动光标
4. 按 `:wq` 保存退出
