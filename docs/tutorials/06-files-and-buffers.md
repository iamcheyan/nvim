# 06 文件与缓冲

> 这一篇讲 Vim 怎么管理「打开的东西」。理解 buffer、window、tab 三者的区别，能避免很多混乱。

## 三个不同的概念

新手常把这三个混在一起。它们是不同层次：

| 概念 | 是什么 | 类比 |
|---|---|---|
| **buffer** | 一个文件在内存里的副本 | 一张纸 |
| **window** | 一个看 buffer 的视口 | 一个相框 |
| **tab page** | 一组 window 的集合 | 一个桌面 |

关键点：

- 一个 buffer 可以同时出现在**多个 window** 里
- 关掉 window **不等于**关掉 buffer
- tab page 不是「标签页」，不是用来切换文件的

详见 [百科：Neovim 架构](../wiki/01-architecture.html)。

## 打开文件

| 命令 | 作用 |
|---|---|
| `:e 文件名` | 打开（edit） |
| `:e!` | 重新载入，丢弃当前修改 |
| `:e .` | 打开文件浏览器 |
| `gf` | 打开光标下的文件路径 |
| `<leader>ff` | 用 picker 找文件 |
| `<leader>fr` | 最近打开的文件 |

日常找文件基本都走 `<leader>ff`——不用记路径，输入片段就筛出来。

## 在 buffer 之间切换

| 命令 | 作用 |
|---|---|
| `:ls` | 列出所有 buffer |
| `:b 名字` | 按名字切 |
| `:b 3` | 按编号切 |
| `:bn` / `:bp` | 下一个 / 上一个 buffer |
| `Shift+l` / `Shift+h` | 这份配置的快捷切换 |
| `<leader>bb` | 跳到上一个访问过的 buffer |

**buffer 没关**的时候文件还在内存里，切回去修改都还在。

## 关掉 buffer

| 命令 | 作用 |
|---|---|
| `:bd` | 关闭当前 buffer |
| `:bd 名字` | 关闭指定 buffer |
| `:bufdo bd` | 关闭所有 |

注意 `:bd` 是关 buffer，`:q` 是关 window。在只有一个窗口的情况下差别不大，多窗口时会很明显。

## 窗口

| 命令 | 作用 |
|---|---|
| `:sp` | 水平分割 |
| `:vs` | 垂直分割 |
| `Ctrl-w` `h/j/k/l` | 在窗口间移动 |
| `Ctrl-w` `w` | 循环切换 |
| `Ctrl-w` `=` | 平均分配大小 |
| `Ctrl-w` `q` | 关闭当前窗口 |
| `Ctrl-w` `o` | 只留当前窗口 |

`Ctrl-h/j/k/l`（这份配置里映射了）比 `Ctrl-w h` 快，直接用。

## tab page

tab 是一组窗口的布局，不是文件标签：

| 命令 | 作用 |
|---|---|
| `:tabnew` | 新 tab |
| `gt` / `gT` | 下一个 / 上一个 tab |
| `:tabclose` | 关当前 tab |

**很多人误以为 tab 是文件标签，结果用 `:tabnew` 打开二十个文件。** 那是 buffer 的活儿。

想要文件「标签栏」的外观，这份配置用 bufferline——它显示的是 buffer 列表，不是 tab。

## 保存

| 命令 | 作用 |
|---|---|
| `:w` | 保存 |
| `:w 新文件名` | 另存为 |
| `:w!` | 强制保存（比如没有权限时用 sudo 技巧） |
| `:wa` | 保存所有 |

**用 sudo 保存只读文件**（不用退出重开）：

```vim
:w !sudo tee %
```

## 退出

| 命令 | 作用 |
|---|---|
| `:q` | 退出（有未保存修改会拒绝） |
| `:q!` | 强制退出，丢弃修改 |
| `:wq` | 保存并退出 |
| `:x` | 同上，但没修改时不写文件 |
| `ZZ` | 保存并退出（普通模式，不用冒号） |

`:x` 比 `:wq` 好一点：没改过就不碰文件时间戳。

## 练习

1. `:e` 打开两个不同文件，`:ls` 看 buffer 列表
2. `:bn` `:bp` 来回切
3. `:vs` 垂直分割，`Ctrl-h` `Ctrl-l` 在两个窗口间移动
4. 在其中一个窗口切 buffer，观察另一个窗口是否也跟着变
5. `:bd` 关掉一个 buffer，确认另一个窗口的表现
6. `ZZ` 退出

**验收**：能说清 buffer、window、tab 三者的区别。

## 关于会话

关掉 Vim 再打开，buffer 列表和窗口布局都没了。想保留：

- `<leader>ws` 保存会话，`<leader>wr` 恢复
- 见 [插件手册：auto-session](../plugins/auto-session.html)
