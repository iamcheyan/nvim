# 12 文本对象

> 上一篇的「动作」是位置（到哪），这一篇的「对象」是结构（一块东西）。

## 区别在哪

| 类型 | 想的是 | 例子 |
|---|---|---|
| 动作 | 位置 | `dw` 到下一个词首 |
| 文本对象 | 结构 | `diw` 当前这个完整的词 |

`diw` 不管你光标在词的哪里，都删掉整个词。`dw` 从光标删到下一个词首——光标在词中间时，只删掉后半截。

**这就是文本对象的价值：不用精确站到边界。**

## 两种形式：`i` 和 `a`

| 前缀 | 含义 | 记忆 |
|---|---|---|
| `i` | inside，不含边界 | inner |
| `a` | around，含边界 | around |

| 对象 | `i` | `a` |
|---|---|---|
| 词 | `iw` 词本身 | `aw` 词 + 后面的空格 |
| 括号 | `i(` 括号内 | `a(` 含括号 |
| 引号 | `i"` 引号内 | `a"` 含引号 |
| 方括号 | `i[` | `a[` |
| 花括号 | `i{` | `a{` |
| 尖括号 | `i<` | `a<` |
| 段落 | `ip` | `ap` |
| 标签 | `it` | `at` |

不同括号可以混用：`di[` `di{` `di(` 都行，Vim 会自动找最近的同类型括号。

## 最常用的六个

| 命令 | 作用 |
|---|---|
| `ciw` | 改掉整个词 |
| `ci"` | 改掉引号里的内容 |
| `ci(` 或 `ci)` | 改掉括号里的内容 |
| `di{` | 删掉花括号里的内容 |
| `yap` | 复制整段（含后面的空行） |
| `vip` | 选中当前段 |

**`ci"` 是改字符串的最快方式**：光标在引号里任意位置，`ci"`，输入新内容，`Esc`。

## `ip` 和 `ap` 的差别

假设文件是这样：

```
第一段第一行
第一段第二行

第二段第一行
第二段第二行
```

- `dip`：删掉当前段落的两行，**留下空行**
- `dap`：删掉当前段落的两行**和结尾的空行**

`dap` 通常是你想要的——删完之后不会留下多余空行。

## 括号对象的智能匹配

`di(` 不用把光标放在括号里。光标在括号内的任意位置都行，甚至贴在括号上也行。

如果括号嵌套：

```c
foo(bar(baz))
```

光标在 `baz` 上按 `di(`，删掉的是 `baz`（最近的一层）。

想删外层的，光标移到外层区域再按。

## 与 Treesitter 相关的对象

这份配置装了 `nvim-treesitter-textobjects`，提供了按语法结构的对象：

| 对象 | 作用 |
|---|---|
| `af` / `if` | 整个函数 / 函数体 |
| `ac` / `ic` | 整个类 / 类体 |
| `ab` / `ib` | 代码块 |
| `ao` / `io` | 条件块（if） |
| `al` / `il` | 循环块 |

`cif` 改整个函数体，`daf` 删整个函数——不用去数大括号。

**注意**：这些需要 Treesitter parser。COBOL 没有 parser，所以这些对象在 `.cob` 文件里不生效（配置里主动禁用了，避免报错）。

## 与 mini.ai 的自定义对象

这份配置还装了 mini.ai，提供额外对象：

| 对象 | 作用 |
|---|---|
| `cia` / `cia` | 参数列表 |
| `cid` | 数字 |
| `cie` | 大小写词 |
| `cig` | 整个 buffer |
| `ciq` | 引号内（同 `ci"`） |

`cig` 特别实用：改整个文件的内容，一步到位。

详见 [插件手册：mini.ai](../plugins/mini-ai.html)。

## 组合示例

**改掉一个函数的所有参数**

光标在参数列表里：`cia`（改参数列表）。

**删掉 if 块里的全部内容**

光标在 if 里：`dio`（删条件块内部）。

**复制整个函数到剪贴板**

`yaf`，再 `"+yaf` 直接进系统剪贴板。

**把 JSON 里某个值改掉**

光标在值上：`ciw` 或 `ci"`（取决于值有没有引号）。

## 练习

打开一份代码文件：

1. 光标停在一个词中间，`ciw` 改掉整个词
2. 在一个字符串里按 `ci"`，改掉内容
3. 在一个函数调用里按 `ci(`，改掉参数
4. `vip` 选中当前段落，`y` 复制，`G` `p` 粘到末尾
5. `dap` 删掉一整段（含空行），`u` 撤销
6. 在 if 块内按 `dio`（需要 Treesitter parser）
7. 光标在文件任意处，`cig` 改整个文件（需 mini.ai）

**验收**：能用 `ciw`、`ci"`、`ci(` 改三种最常见的结构，不用先移动光标到边界。
