# 11 操作符与动作语法

> 这是 Vim 的核心语法。懂了它，不用背几百个按键——能自己推出来。

## 基本公式

```
操作符 + 动作 = 一次编辑
```

| 操作符 | 作用 |
|---|---|
| `d` | 删除 |
| `c` | 修改（删除并进入插入模式） |
| `y` | 复制 |
| `>` / `<` | 缩进 / 反缩进 |
| `=` | 自动缩进 |
| `g~` / `gU` / `gu` | 切换大小写 / 转大写 / 转小写 |
| `!` | 过滤（走外部命令） |
| `gq` | 格式化（按 `textwidth` 折行） |

| 动作 | 范围 |
|---|---|
| `w` | 到下一个词首 |
| `e` | 到当前词尾 |
| `$` | 到行尾 |
| `0` | 到行首 |
| `j` / `k` | 下一行 / 上一行 |
| `}` / `{` | 下一段 / 上一段 |
| `f<char>` | 到本行下一个指定字符 |
| `t<char>` | 到该字符之前 |
| `/pattern` | 到下一个匹配 |

组合起来：

```
dw      删到下一个词
d$      删到行尾
d}      删到段落结束
df)     删到下一个右括号
dt,     删到下一个逗号之前
```

## 为什么这个设计好

**组合数 = 操作符数 × 动作数**。

8 个操作符 × 15 个常用动作 = 120 个可用组合，但只需要记 23 个东西。

而且新加一个动作，所有操作符自动支持它——比如知道 `d/foo` 能「删到 foo」，那 `c/foo`（改到 foo）、`y/foo`（复制到 foo）自然就会。

## 双写 = 整行

同一个字母重复，表示「整行」：

| 写法 | 等价于 |
|---|---|
| `dd` | `d0d$`（删整行）|
| `cc` | 改整行 |
| `yy` | 复制整行 |
| `>>` | 整行缩进 |
| `==` | 整行自动缩进 |

这个规律在很多命令上都成立，包括 `gUU`（整行转大写）、`guu`（整行转小写）。

## 加计数

```
d3w     删 3 个词
2dd     删 2 行
5>>     5 行缩进
```

**计数放在操作符和动作之间**也行（`d3w`），放在前面也行（`3dw`）。两者等价，习惯哪个用哪个。

## 点号重复

`.` 重复的是**整个操作**，不只是最后一个按键。

```
dw      删一个词
.       再删一个词
.       再删一个
```

改一处，`.` 一路重放。这是 Vim 效率的核心。

**但 `.` 只重复「引起修改」的操作**——移动、搜索不算。所以「移动 + 修改」的节奏是：

```
dw      修改（. 会记住这个）
j       移动（不破坏 . 的记忆）
.       重放删除
j.
j.
```

这个 `修改 → 移动 → 点` 的节奏，是批量改文件最有效的模式。

## `f` 和 `t`：行内精确定位

| 写法 | 含义 |
|---|---|
| `f,` | 到本行下一个逗号上 |
| `t,` | 到逗号**前**一个字符 |
| `F,` | 往前找（大写反向） |
| `;` | 重复上次 `f`/`t` |
| `,` | 反向重复 |

`df,` 删到逗号（含），`dt,` 删到逗号前（不含）。改逗号分隔的列表时这两个极常用。

## `g` 前缀的操作符

`g` 是个「次级前缀」，把某些操作变成操作符：

| 组合 | 作用 |
|---|---|
| `g~~` | 整行切换大小写 |
| `gUU` | 整行转大写 |
| `guu` | 整行转小写 |
| `gUiw` | 当前词转大写 |
| `gqap` | 格式化当前段落 |

## 组合示例：真实场景

**把一个函数调用里的参数全删掉，保留括号**

光标在括号内：`di(` —— 这是文本对象，下一篇讲。用动作的话：`dt)`。

**删掉从光标到下一个空行**

`d}`。

**改掉从光标到行尾的所有内容**

`C`（= `c$`）。

**把这一段重新折行**

`gqip` 或 `gqap`。

## 练习

打开任意代码文件：

1. `dw` 删一个词，`u` 撤销
2. `d$` 删到行尾，`u`
3. `3dd` 删三行，`u`
4. `df,` 删到逗号，`u`；再试 `dt,` 对比差别
5. `cw` 改一个词，`Esc`，`j.` `j.` 连续改三个
6. `gUiw` 把一个词转大写，`u`
7. `gqap` 格式化整段

**验收**：能不看文档推出 `ct)` 的作用（改到右括号前）。

## 这个语法的边界

有些操作不是「操作符+动作」：

- `r`（替换一个字符）——它是独立的
- `p`（粘贴）——独立
- `~`（切换大小写）——独立

它们不接范围，但有别的组合方式（`r` 可以接计数：`5rX` 替换 5 个字符）。
