# 10 正则与 `:g`

> Vim 的正则和 Perl/Python 的不完全一样，但有 `\v` 可以变过来。`:g` 是批量操作的入口。

## 先解决一个混乱：四种 magic 级别

Vim 的正则默认写法很啰嗦（到处 `\(` `\)` `\+`）。原因是历史上为了兼容。

| 级别 | 写法 | 效果 |
|---|---|---|
| magic（默认） | `\(foo\)\+` | 要转义才特殊 |
| `\v` very magic | `(foo)+` | 像普通正则 |
| `\V` very nomagic | `foo` | 只有 `\` 特殊 |
| `\m` / `\M` | 中间态 | 少用 |

**建议**：一律用 `\v`。

```vim
:%s/\v(\w+)\.cob/\1.cbl/g
```

比默认写法的 `:%s/\(\w\+\)\.cob/\1.cbl/g` 清楚得多。

## 常用元字符

在 `\v` 下：

| 写法 | 含义 |
|---|---|
| `.` | 任意一个字符 |
| `*` | 前一项 0 次或多次 |
| `+` | 前一项 1 次或多次 |
| `?` | 前一项 0 或 1 次 |
| `{2,4}` | 2 到 4 次 |
| `(...)` | 分组 |
| `\|` | 或 |
| `^` `$` | 行首 / 行尾 |
| `\d` `\w` `\s` | 数字 / 词字符 / 空白 |
| `\zs` `\ze` | 匹配起止点（只对这部分操作） |
| `\<` `\>` | 词边界 |

### `\zs` 和 `\ze` 值得单独说

它们让你「匹配一整段但只操作其中一部分」：

```vim
:%s/\vfoo \zs bar/baz/g
```

这个会匹配 `foo bar`，但只替换 `bar`。写替换时非常有用，比用捕获组省事。

## `:g` 全局命令

语法：

```vim
:g/模式/命令        对匹配的行执行命令
:g!/模式/命令       对**不**匹配的行执行（= :v）
```

这是批量处理的核心工具。

### 常见用法

**删掉所有含 TODO 的行**

```vim
:g/TODO/d
```

**把含 import 的行收集到文件末尾**

```vim
:g/^import/t$
```

`t` 是 copy（复制到指定位置），`t$` 是复制到末尾。

**把所有空行压缩成一行**

```vim
:g/^$/d
```

**只保留含某个词的行**

```vim
:v/关键词/d
```

`:v` 是 `:g!` 的简写。

**给每个函数定义加注释**

```vim
:g/^function/ s/$/  \-- 自动生成/
```

` :g` 找到匹配行，`s/$/.../` 在行尾追加。

## `:g` 配合 `normal`

这是最有力也最容易出错的组合：

```vim
:g/^ \* /normal! A -- done
```

对每个以 ` * ` 开头的行，行尾加 ` -- done`。

**必须用 `normal!`**（带感叹号），否则用户自定义的映射会介入，结果不可预测。

## 捕获组与替换

```vim
:%s/\v(\w+)-(\w+)/\2-\1/g
```

把 `foo-bar` 换成 `bar-foo`。

| 引用 | 含义 |
|---|---|
| `\1` `\2` | 第 1、2 个分组 |
| `\0` 或 `&` | 整个匹配 |
| `\u` `\l` | 下一个字符变大写 / 小写 |
| `\U` `\L` | 之后都变大写 / 小写 |

`\u` 很实用：`:%s/\v\w+/\u&/g` 把每个词的第一个字母大写。

## greedy 陷阱

默认 `*` 和 `+` 是**贪婪**的，会尽可能多匹配：

```vim
" 想删掉引号里的内容
:%s/\v".*"/""/g
```

`.*` 会匹配到**最后一个**引号，把中间全吃掉。加上 `?` 变成非贪婪：

```vim
:%s/\v".-"/""/g
```

Vim 里非贪婪是 `{-}` 或 `{-1,}`，在 `\v` 下 `.-` 也行。

这个坑在原书里就专门讲了一节，二十多年后依然是新手最容易踩的。

## 什么时候不该用正则

正则处理不了嵌套结构。比如「匹配一个括号内的内容，如果里面有嵌套」——这需要解析器。

这时候：

- 结构化的代码用 Treesitter（见 [百科：Treesitter](../wiki/05-treesitter.html)）
- 跨文件替换用 grug-far，先看匹配数
- 复杂改写写脚本，不要硬套正则

## 练习

1. `:g/^$/d` 删掉文件里所有空行，`u` 撤销
2. `:v/TODO/d` 只保留含 TODO 的行，`u` 撤销
3. `:%s/\v(\w+)@(\w+)/\2 at \1/g` 交换邮箱格式
4. `:g/^class/normal! A  # 待审查` 给每个 class 行加注释
5. 试试 `:%s/\v".*"/""/g` 和 `:%s/\v".-"/""/g` 的区别
6. `:g/foo/t$` 把所有含 foo 的行复制到文件末尾

**验收**：能说清 `\v` 的作用，能看出贪婪匹配造成的问题。
