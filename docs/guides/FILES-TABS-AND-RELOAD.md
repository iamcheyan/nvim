# 新建文件、文件条与配置重载

## 新建文件

| 入口 | 行为 |
|---|---|
| 顶部 `+`、`<leader>fn`、编辑区或文件条的 New File 菜单 | 在底部命令栏询问文件名，然后在新 tab page 打开 |
| `<leader>N`（普通模式） | 跳过询问，用默认文件名在新 tab page 打开 |
| Neo-tree 的 New File | 在树中选定的目录创建文件，保留文件树的目录语义 |

默认名称为当前目录下的 `new-file.txt`。磁盘或已打开的 buffer 已占用该名称时，
依次使用 `new-file-2.txt`、`new-file-3.txt`。输入框直接回车接受预填名称；清空后回车
也使用可用的默认名称。取消输入不新建文件。打开后通过 `:w` 才把内容写入磁盘。

保留 Neovim 原生命令的行为：`:new` 是水平分屏，`:tabnew` 是新 tab page。
输入框预填内容可用 `Ctrl+U` 清空后替换。

## 文件条与 tab page

顶部文件条展示所有已列出的文件 buffer；每个文件标签代表一份正在编辑的内容。
右侧的数字 tab 指示代表 Neovim 的 tab page，即一组窗口布局。多于一个 tab page 时，
可以点击编号切换；也可以用 `<leader><tab><tab>` 打开布局列表。

点击文件标签时，优先回到已经显示该文件的窗口：先找当前 tab，再找其它 tab；
没有窗口显示它时才在当前编辑窗口打开。文件标签的关闭按钮关闭该 buffer，
因此会影响其它 tab 中显示同一 buffer 的窗口。修改未保存时仍会询问保存、放弃或取消。
`:tabclose` 则只关闭当前布局页，并遵循 Neovim 的未保存检查。

## 快捷键

`<leader>N` 只负责新建默认命名文件。多光标的下一/上一匹配改为
`<leader>mn` / `<leader>mN`，普通和可视模式一致；`Ctrl+n` 和 `Ctrl+Shift+n`
仍分别添加下一匹配和全部匹配。`<leader>ni` / `<leader>nd` 留给数字递增/递减，
避免把一个即时动作放在这两个快捷键的前缀上。

## 定向重载配置

执行 `:ConfigReload`、按 `<leader>uR`，或点击底部模式区并选择 Reload Configuration
打开重载菜单，也可直接指定范围：

| 命令 | 重载范围 |
|---|---|
| `:ConfigReload keymaps` | 通用、个人及多光标快捷键 |
| `:ConfigReload files` | 新建、保存、关闭等文件操作 |
| `:ConfigReload statusline` | 状态栏、点击菜单与位置显示 |
| `:ConfigReload all` | 以上三个范围 |

重载状态栏会先关闭现有菜单并还原临时按键，不重复创建计时器或自动命令。
重载菜单中的 all 只表示以上已支持的模块。修改插件安装清单、LSP、Treesitter、
启动选项或会话配置时，仍应重启 Neovim。

## 位置显示

点击底部 `L…C…P…` 可查看说明、跳转行/列或复制位置。
`L` 是行号，`C` 是屏幕单元列，`P` 是当前行的字节位置；均从 1 开始。
中文、制表符等会使 `C` 和 `P` 不同，跳转到列按 `C` 的屏幕列含义执行。
