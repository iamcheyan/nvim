# fidget.nvim

> 公开插件 · [回到插件目录](../PLUGINS.md)

## 它解决什么问题

LSP 在后台索引、诊断、格式化时，界面没有任何反馈，你不知道它在忙还是卡住。
fidget 在右下角显示进度通知，让你知道「正在等 LSP」。

## 在当前配置里怎么用

没有按键。LSP 有进度时自动出现，结束后自动消失。

显示的内容可能是：

- 索引工作区
- 加载项目
- 诊断计算
- 格式化进行中

### 什么时候你会注意它

1. **刚打开大项目**，LSP 在索引，右下角有旋转提示。
2. **保存后格式化**，短暂显示。
3. **卡住时**——如果提示一直在转，说明 LSP 没响应，这时才需要排查。

## 动手练习

1. 打开一个大项目里的文件，观察右下角是否出现进度提示。
2. 等它消失后再 `gd` 跳转，确认跳转可用（索引完成）。
3. 在提示还在转的时候尝试 `gd`，观察行为差异。
4. `:LspInfo` 看服务器状态。

**验收**：能看到 LSP 的活动反馈，并能据此判断「是不是还在索引」。

## 注意事项

- **提示消失不代表没问题**，有些服务器不发送进度。
- **提示一直不消失说明有问题**：服务器崩溃或卡住，用 `:LspInfo` / `:checkhealth lsp` 排查。
- 它只是显示器，不改变 LSP 行为。
- 通知位置和其它通知插件可能重叠，配置已做排除。
