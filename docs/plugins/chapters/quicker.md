# quicker.nvim

> 公开插件 · [回到插件目录](../PLUGINS.md)

## 它解决什么问题

改善 quickfix 列表的阅读和批量修改体验。搜索、编译等命令生成的结果可以显示相关上下文，也可以在列表中编辑多处匹配。

## 在当前配置里怎么用

用 `<leader>xq` 打开 quickfix 列表，或运行 `:copen`。在列表中按 `>` 展开每条结果前后各两行上下文；按 `<` 收起。回到结果行按 Enter 跳转到对应文件和位置。`[q` / `]q` 在结果间移动。

## 动手练习

运行 `:vimgrep /TODO/j **/*` 建立结果列表，再按 `<leader>xq` 打开。选中一项按 `>` 查看周围代码；按 `<` 收起，按 Enter 跳转。

## 注意事项

插件只在 quickfix 窗口加载。修改 quickfix 项目会修改对应文件；保存前先确认变更范围。位置列表仍可用 Neovim 的 `:lopen` / `:lclose`。

## 查快捷键和帮助

运行 `:help quicker` 查看上下文、编辑和配置选项；`<leader>?` 可查看当前快捷键。
