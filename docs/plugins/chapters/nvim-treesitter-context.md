# nvim-treesitter-context

> 公开插件 · [回到插件目录](../PLUGINS.md)

## 它解决什么问题

滚到函数中间时，上面的函数签名和外层结构已经滚出屏幕，只能靠记忆或往上翻。这个插件把当前所处的函数、类或块的头部固定在窗口顶部，滚动时始终能看到自己在哪个结构里。

它和 `dropbar.nvim` 不同：dropbar 显示在 winbar，这个是浮动在缓冲区上方的虚拟行。

## 在当前配置里怎么用

不需要按键，打开文件自动生效。手动控制：

| 命令 | 作用 |
|---|---|
| `:TSContext enable` | 启用 |
| `:TSContext disable` | 停用 |
| `:TSContext toggle` | 切换 |

配置要点：

- `max_lines = 3`：最多显示 3 行上下文，避免占满小窗口。
- `min_window_height = 12`：窗口低于 12 行时不显示。
- `mode = "cursor"`：跟随光标所在的结构，而不是窗口顶行。
- `line_numbers = true`：上下文行也显示行号，和左侧对齐。
- `separator = nil`：不额外占用一行作为分隔符窗口，保持紧凑；由底层高亮在末行绘制清晰底部分界线。

## 视觉与多主题适配设计

为了保证在所有主题与文档类型下均能清晰辨识、不突兀、不刺眼，系统提供了全场景自适应高亮引擎（相关实现：`lua/config/ui_highlights.lua` 与 `lua/config/markdown_typography.lua`）：

1. **经典 Nostalgia 蓝色主题 (`colorscheme blue`)**：
   - 保持深邃沉浸的深蓝微暗底色 (`#00005f`)，搭配青蓝底部分界线 (`#005faf`)，与代码主体完美呼应。
2. **纯黑与深黑主题 (`oceanblack` 或背景亮度极低的主题)**：
   - 自动将上下文浮层提亮为质感暗炭灰 (`#171717`)，并生成高对比的底边细线 (`#404040`)，彻底解决过去“黑背景与代码融为一体、看不清边界”的痛点。
3. **现代暗色主题 (`habamax`, `retrobox`, `catppuccin` 等)**：
   - 依据背景相对亮度微量平移明度，保持浮层阶梯感与清晰的下边框，代码语法高亮原汁原味透传保留。
4. **浅色主题 (`delek`, `quiet` 等)**：
   - 采用柔和的纸白浅灰微调色 (`#f2f2f2`) 与淡灰底线 (`#cccccc`)，杜绝过去粗暴叠加 30% 黑色导致的“脏灰泥块”现象。
5. **Markdown 文档与富文本专属模式 (`markdown_typography`)**：
   - 当在 Markdown 缓冲区滚动时，上下文浮层自动接入窗口本地的独立纸张排版命名空间，采用护眼浅纸底色 (`#f5f5f5`)、Delek 标红行号 (`#a52a2a`) 与浅灰下边框 (`#bcbcbc`)，标题高亮同步保持文档级色彩，彻底杜绝蓝色背景泄漏进文档。

## 动手练习

1. 打开一个有嵌套结构的长文件（例如本仓库的 `lua/plugins/*.lua`）。
2. 滚到函数中间，确认窗口顶部出现该函数签名。
3. 进入内层块，确认上下文随光标更新。
4. `:TSContext disable` 确认顶部行消失，再 `:TSContext enable` 恢复。

**验收**：滚动时顶部始终显示所属结构；小窗口下自动隐藏。

## 注意

- 依赖 Treesitter 解析器；没有对应语言解析器时不会显示。
- 上下文是虚拟行，不会被保存进文件，也不会被 `gg`/`G` 计入行号。
