# goto-preview

> 公开插件 · [回到插件目录](../PLUGINS.md)

## 它解决什么问题

`gd` 直接跳走会丢失当前位置：看完定义要再跳回来，来回多次很累。这个插件把定义、实现和引用放在浮动窗口里预览，当前窗口和光标位置不变。

## 在当前配置里怎么用

| 按键 | 作用 |
|---|---|
| `gpd` | 预览定义 |
| `gpi` | 预览实现 |
| `gpr` | 预览引用 |
| `gP` | 关闭所有预览窗口 |

窗口默认 80×20，标题显示文件路径。`default_mappings = false`：不使用插件自带的映射，避免覆盖本配置已有的按键。

## 动手练习

1. 打开一个 LSP 已就绪的文件，把光标放在函数调用上。
2. `gpd`，确认浮动窗口里出现定义，且原窗口没变。
3. 在预览窗口里 `:q` 或按 `q` 关闭（也可 `gP` 一次关全部）。
4. 对接口或抽象方法用 `gpi`，对变量用 `gpr`。

**验收**：预览出现在浮动窗口；关闭后光标仍在原处。

## 注意

- 需要 LSP；没有语言服务器时不会有结果。
- 预览窗口是普通窗口，可以正常滚动、复制，也可以 `:q` 单独关掉。
