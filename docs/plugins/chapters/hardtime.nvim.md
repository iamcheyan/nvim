# hardtime.nvim

> 公开插件 · [回到插件目录](../PLUGINS.md)

## 它解决什么问题

习惯性地用 `jjjjj` 往下移、用 `xxxx` 删字符，效率不高也累手。Hardtime 会在你重复低效按键时给出提示，逼着用更短的动作（数字前缀、词级移动、文本对象）。

## 在当前配置里怎么用

**默认关闭**，需要时才开：

| 命令 | 作用 |
|---|---|
| `:Hardtime enable` | 启用 |
| `:Hardtime disable` | 停用 |
| `:Hardtime toggle` | 切换 |
| `:Hardtime report` | 查看统计报告 |

相关选项：`max_count = 3`（同一键连续 3 次才提示）、`max_time = 1000`（时间内重复才算）、`allow_different_key = true`（换键不算重复）。

## 动手练习

1. `:Hardtime enable`。
2. 连续按 `j` 五次，确认出现提示，建议改用 `5j` 之类。
3. 用 `5j` 再试，确认不再提示。
4. `:Hardtime report` 查看被拦下的次数。
5. `:Hardtime disable` 恢复正常手感。

**验收**：启用后重复按键有提示；用数字前缀或词级移动时不提示。

## 注意

- 默认关闭是有意的：这个插件会「打断」输入，建议在练习时段开，日常编辑关掉。
- 写代码或需要快速试错时先关闭，避免频繁提示影响节奏。
