# undotree

> 公开插件 · [回到插件目录](../PLUGINS.md)

## 它解决什么问题

`u` 只能沿着当前撤销分支后退。实际编辑常常分叉：改到一半撤回、换个写法重来，旧的那条分支并没有消失，但普通撤销看不到它。undotree 把撤销历史画成一棵树，可以看到所有分支，并直接跳到任意一个状态继续编辑。

## 在当前配置里怎么用

| 按键 | 作用 |
|---|---|
| `<leader>uu` | 打开或关闭撤销树 |

面板默认在左侧打开，宽度 30；下方是可选的 diff 面板，用来对比选中状态与当前内容。

### 面板内按键

| 按键 | 作用 |
|---|---|
| `J` / `K` | 上一个 / 下一个撤销状态 |
| `<CR>` | 切换到当前选中的状态 |
| `u` / `<C-r>` | 撤销 / 重做 |
| `D` | 显示或隐藏 diff 面板 |
| `T` | 切换相对时间戳 |
| `?` | 显示帮助 |
| `q` | 关闭面板 |
| `<Tab>` | 把焦点交回编辑窗口 |

### 持久化撤销

配置里启用了 `undofile`，撤销历史会写盘，关闭 Neovim 再打开同一个文件仍能恢复分支。撤销文件默认保存在 Neovim 的 state 目录，可以用 `:echo undofile(bufname('%'))` 查看具体路径。

撤销历史按文件路径保存。文件被移动或改名后，旧历史不会自动跟随，需要手动重命名对应的撤销文件。

## 动手练习

1. 新建临时文件，输入 `one` 并保存。
2. 改成 `two`，保存。
3. 按 `u` 撤回一步，改成 `three`，保存。此时历史出现两个分支。
4. 按 `<leader>uu` 打开撤销树，确认能看到 `two` 和 `three` 两条分支。
5. 用 `J` / `K` 选中 `two`，按 `<CR>`，确认文件内容回到该状态。
6. 按 `q` 关闭面板。

**验收**：树上能看到分叉，切换状态后文件内容随之改变；关闭再打开文件，历史仍在（前提是文件路径没变）。

## 注意

- diff 面板会额外占用垂直空间，屏幕较矮时用 `D` 关掉。
- 撤销文件属于本地缓存，清理 state 目录会一并删除历史。
