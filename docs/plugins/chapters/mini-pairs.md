# mini.pairs

> 公开插件 · [回到插件目录](../PLUGINS.md)

## 它解决什么问题

输入 `(` 自动补 `)`，输入 `"` 自动补 `"`，并且在已配对处按右括号时**跳过**而不是插入。
省掉大量手动的括号输入。

## 在当前配置里怎么用

没有独立按键，插入模式自动生效：

| 输入 | 结果 |
|---|---|
| `(` | `()`，光标在中间 |
| `"` | `""`，光标在中间 |
| 在 `)` 上按 `)` | 光标跳过，不重复插入 |
| `<BS>` 在空对之间 | 一次删掉两边 |

### 与 COBOL 的冲突

COBOL 的 `PIC X(10)` 里括号是**声明的一部分**，不是需要配对的代码块，
而且 `PERFORM 段落名` 是裸名字调用。因此配置在 COBOL 里做了限制：
autopairs 类的自动补全对 COBOL 关闭。

同时 blink.cmp 的 `auto_brackets` 也排除了 `cobol` / `cbl` / `cob`。两处配合，
确保 COBOL 不会被自动括号破坏。

## 动手练习

1. 在 Lua 文件插入模式输入 `(`, 确认补上 `)`。
2. 输入 `"`，确认补上成对引号。
3. 在 `()` 中间按 `)`，确认光标跳过而不是插入第二个。
4. 在空 `()` 里按 `<BS>`，确认一次删掉两个。
5. 在 COBOL 文件里输入 `(`, 确认**没有**自动补全。

**验收**：普通语言正常配对，COBOL 不自动加括号。

## 注意事项

- **COBOL 里已禁用**，因为 COBOL 的括号语义不同。
- **与 blink.cmp 的 auto_brackets 是两层防护**，改一处不够。
- **`mini.pairs` 不支持多字符配对**（如 `<!-- -->`），那是别的插件的职责。
- 在字符串里输入引号仍会配对，这是常见行为，撤销用 `u`。
