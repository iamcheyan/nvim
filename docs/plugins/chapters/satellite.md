# satellite.nvim

> 公开插件 · [回到插件目录](../PLUGINS.md)

## 它解决什么问题

长文件里「哪里改过、哪里有错、搜索命中的在哪」在屏幕外看不到。
satellite 在窗口右边缘画标记，把分布可视化。它类似编辑器的 minimap，
但只画标记不画代码。

## 在当前配置里怎么用

| 配置项 | 值 | 含义 |
|---|---|---|
| `current_only` | `false` | **所有窗口**都画，不只是当前窗口 |
| `winblend` | `0` | 不透明，标记清晰 |
| `zindex` | `40` | 层级，低于浮窗 |
| `excluded_filetypes` | 一长串 | 侧栏、菜单、picker 不画 |

### 标记来源

- **Git 改动**（来自 gitsigns）
- **诊断**（错误/警告）
- **搜索命中**（`hlsearch`）
- **光标位置**

### 排除清单的意义

`excluded_filetypes` 里有 `neo-tree`、`noice`、`blink-cmp-menu`、`TelescopePrompt`、
`prompt` 等。这些窗口是浮层或侧栏，在上面画标记只会干扰。

## 动手练习

1. 打开一个长文件，改几处并保存，观察右边缘出现标记。
2. 在文件里制造一个语法错误，确认出现诊断标记。
3. 搜索一个常见词，确认搜索命中也被标出。
4. 打开 Neo-tree 侧栏，确认侧栏上**没有**标记。
5. 分屏成两个窗口，确认两个窗口都有标记（`current_only = false`）。

**验收**：改动能被即时标记，浮层和侧栏不受影响。

## 注意事项

- **它不显示代码内容**，只显示标记位置，所以不消耗渲染性能。
- **依赖其它插件的数据**：没有 gitsigns 就没有 Git 标记。
- **`current_only = false` 是有意的**，分屏工作时能看到另一个窗口的分布。
- 标记颜色与主题高亮组绑定。
