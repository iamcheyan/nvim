# hlchunk.nvim

> 公开插件 · [回到插件目录](../PLUGINS.md)

## 它解决什么问题

光标在深层嵌套里时，很难一眼看清当前所属的括号或块边界。这个插件给当前所在的块画一条竖线和拐角，把「我现在在哪一层」变成可见的几何形状。

## 在当前配置里怎么用

默认自动启用，没有必须记住的按键：

| 按键 | 作用 |
|---|---|
| `<leader>uH` | 停用块高亮（`:DisableHLChunk`） |
| `<leader>uG` | 启用块高亮（`:EnableHLChunk`） |

配置里**只启用了 `chunk`**。原因是 `indent-blankline` 已经在画缩进参考线，如果再开 hlchunk 的 `indent`、`line_num`、`blank` 会重复叠加，界面反而更乱。需要那些效果时，把 `indent = { enable = true }` 打开并关掉 indent-blankline 即可。

## 动手练习

1. 打开一个有多层括号或缩进的文件。
2. 把光标移到最内层，确认左侧出现竖线和拐角，指向当前块的上下边界。
3. 向外移动一层，确认高亮跟着换到外层。
4. `<leader>uH` 关闭，确认线条消失；`<leader>uG` 再打开。

**验收**：高亮始终标记光标所在的那一层；关闭命令即时生效。

## 注意

- 依赖 Treesitter 或括号匹配；纯文本文件不会显示。
- 如果和缩进线看起来重复，只需保留其中一种。
