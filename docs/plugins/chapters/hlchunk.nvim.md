# hlchunk.nvim

> 公开插件 · [回到插件目录](../PLUGINS.md)

## 它解决什么问题

光标在深层嵌套里时，很难一眼看清当前所属的括号或块边界。这个插件给当前所在的块画一条竖线和拐角，把「我现在在哪一层」变成可见的几何形状。

## 在当前配置里怎么用

默认自动启用，无快捷键开关。配置里**只启用了 `chunk`**，避免和 snacks.nvim 的缩进线重复叠加。动画时长设为 0ms，光标移动时立即刷新块高亮，不做淡入淡出。`indent`、`line_num`、`blank` 均关闭。

## 动手练习

1. 打开一个有多层括号或缩进的文件。
2. 把光标移到最内层，确认左侧出现竖线和拐角，指向当前块的上下边界。
3. 向外移动一层，确认高亮跟着换到外层。
4. 快速移动光标，确认块边界立即跟随更新，没有淡入淡出动画。

**验收**：高亮始终标记光标所在的那一层；更新没有动画延迟。

## 注意

- 依赖 Treesitter 或括号匹配；纯文本文件不会显示。
- 如果和缩进线看起来重复，只需保留其中一种。
