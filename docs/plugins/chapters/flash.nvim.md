# flash.nvim

> 公开插件 · [回到插件目录](../PLUGINS.md)

## 它解决什么问题

屏幕内的跳转用 `f`/`t` 只能找单个字符，用搜索又太吵。Flash 让你「输入一两个字符，
按屏幕上的标签直接跳过去」，并且能配合操作符做远程编辑。

## 在当前配置里怎么用

| 按键 | 模式 | 作用 |
|---|---|---|
| `s` | n / x / o | 输入目标字符，按标签跳转 |
| `S` | n / x / o | 按 Treesitter 节点跳转 |
| `<C-s>` | 命令行 | 切换 Flash 搜索提示 |

在操作符待决模式也能用：`d s )` 表示「删到目标括号」。

### 按键取舍

配置**没有**把 `r` 和 `R` 绑给 Flash：

```lua
-- 移除了 r 和 R 的映射，避免与 substitute.nvim 冲突
```

这是有意的：`r` 是替换单个字符的高频操作，交出去代价太大。

## 动手练习

1. 打开一个长文件，`s` 后输入一个附近独特的字符，按显示的标签跳过去。
2. 在函数名上按 `S`，用 Treesitter 节点跳转。
3. `d s` 再接一个括号，删除到目标位置，`u` 撤销。
4. 在搜索命令行里按 `<C-s>`，观察提示变化。
5. 确认 `r` 仍是替换字符、`R` 仍是替换模式。

**验收**：`s`/`S` 跳转顺畅，且 `r`/`R` 保持原生语义。

## 注意事项

- **目标太多时补充字符**。第一次 `s` 后标签太密，说明该字符太常见，
  继续输入第二个字符缩小范围。
- **`Esc` 可随时退出**。
- **`r`/`R` 未绑定是有意的**，不要为了「功能完整」再绑上。
- Treesitter 节点跳转需要对应语言的 parser。
