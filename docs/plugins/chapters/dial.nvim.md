# dial.nvim

> 公开插件 · [回到插件目录](../PLUGINS.md)

## 它解决什么问题

`Ctrl-a` / `Ctrl-x` 只能加减数字，而且在本配置里 `<C-a>` 被占用（全选）、`<C-x>` 在可视模式是剪切到剪贴板。Dial 提供可配置的递增/递减：数字、十六进制、日期、布尔值和语义化版本号都能按上下文正确变化。

## 在当前配置里怎么用

| 按键 | 作用 |
|---|---|
| `<leader>ni` | 递增（普通模式） |
| `<leader>nd` | 递减（普通模式） |
| `<leader>ni` | 递增（可视模式，逐行递增） |
| `<leader>nd` | 递减（可视模式） |

已注册的「augend」类型：十进制整数、十六进制、`%Y/%m/%d` 日期、`true/false` 布尔值、语义化版本号（`1.2.3`）。

## 动手练习

1. 在一行 `count = 41` 上把光标放到 `41`，按 `<leader>ni`，确认变成 `42`。
2. 在日期 `2026/10/22` 上按 `<leader>ni`，确认日期前进一天。
3. 在 `true` 上按 `<leader>ni`，确认变成 `false`。
4. 在版本号 `1.2.3` 上按 `<leader>ni`，确认按段递增。
5. 选中多行数字后按 `<leader>ni`，确认逐行递增。

**验收**：不同类型都能按各自规则变化；`<C-a>`（全选）不受影响。

## 注意

- 刻意没有占用 `<C-a>` / `<C-x>`：这两个键在本配置里已有用途。
- 需要更多类型（星期、月份、时区）时，在 spec 的 `augends` 里继续注册即可。
