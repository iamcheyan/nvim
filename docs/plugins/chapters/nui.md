# nui.nvim

> 依赖 · [回到插件目录](../PLUGINS.md)

## 它解决什么问题

Neovim 的浮窗 API 很底层：位置、边框、高亮、事件都要自己算。
nui.nvim 提供组件化的 UI 抽象（Popup、Input、Menu、Split、Layout），
让插件能快速做出体面的浮层界面。

**它是依赖，不是给你直接用的插件。**

## 在当前配置里怎么用

没有按键和命令。它在两个地方被间接使用：

| 使用方 | 用途 |
|---|---|
| noice.nvim | 命令行和消息的浮层渲染 |
| 各类菜单/输入浮窗 | 统一的边框与布局 |

配置里还有一份 [浮窗 UI 设计约定](../development/floating-window-ui.html)，
规定 NUI／Noice 和全局浮窗样式之间怎么配合——**要改浮窗外观，先读那份文档**。

## 动手练习

1. 触发一个浮窗界面（如 `:Noice` 或 picker 的输入框）。
2. 观察边框、标题、内边距的统一性。
3. 读一遍浮窗 UI 设计约定，确认哪些是全局样式、哪些是单插件覆盖。

**验收**：能区分「这是 nui 提供的样式」和「这是插件自己画的」。

## 注意事项

- **不要直接改 nui**，改使用它的插件或全局浮窗样式。
- **浮窗样式分散在多处**：nui、noice、全局 `winhighlight`。
  统一改动前先读设计约定，避免只改了一处。
- 它是纯依赖，没有用户可见入口。
