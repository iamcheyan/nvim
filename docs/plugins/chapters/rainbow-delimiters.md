# rainbow-delimiters.nvim

> 公开插件 · [回到插件目录](../PLUGINS.md)

## 它解决什么问题

`((a + b) * (c - d))` 这种嵌套括号，靠眼睛配平容易错。彩虹括号按嵌套层级上色，
一眼看出哪对括号是一层。

## 在当前配置里怎么用

没有按键，打开文件自动生效。配置只改了一处策略：

```lua
strategy = {
  [""] = rainbow.strategy["global"],
  vim = rainbow.strategy["local"],
}
```

**VimScript 文件用 `local` 策略**。原因是 VimL 的括号嵌套很深且常有字符串里的
括号，全文件分析容易卡；局部策略只看可见区域。

## 动手练习

1. 打开一个嵌套较深的 Lua 文件，观察括号的层级配色。
2. 把光标移到一对括号上，确认同层括号颜色相同。
3. 打开一个 `.vim` 文件，确认它用局部策略（大文件滚动时不卡顿）。
4. 在一个只有单层括号的文件里确认颜色不跳变。

**验收**：同层同色，不同层不同色，`.vim` 文件滚动流畅。

## 注意事项

- **颜色来自主题的高亮组**，换主题会一起换；不要硬编码颜色。
- **对 COBOL 作用有限**。COBOL 的括号多用于 `PIC X(10)` 这类，
  嵌套不深，视觉收益不大。
- **策略差异是有意的**，不要统一成 global，`.vim` 大文件会变慢。
- 括号配色不改变文本内容，只是高亮。
