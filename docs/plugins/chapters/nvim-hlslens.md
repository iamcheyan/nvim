# nvim-hlslens

> 公开插件 · [回到插件目录](../PLUGINS.md)

## 它解决什么问题

`*` 搜索后，你只能看到屏幕内的命中，不知道全文有多少处、现在在第几处。
hlslens 在搜索结果旁显示「3/17」这样的位置计数，并支持虚拟文本提示。

## 在当前配置里怎么用

没有专用按键，`*` / `#` / `n` / `N` 搜索后自动显示。

| 操作 | 效果 |
|---|---|
| `*` / `#` | 搜索光标下单词，显示命中计数 |
| `n` / `N` | 前后跳，计数实时更新 |
| 浮窗提示 | 显示当前位置 / 总数 |

### 配置里的取舍

这份配置把 `n` / `N` 做了**方向感知 + `zv`**处理（跳转后自动展开折叠），
并在映射里调用 `hlslens.start()` 让计数刷新。所以 `n` 不只是原生搜索，
还兼顾了折叠展开和计数更新。

## 动手练习

1. 在一个大文件里 `*` 搜索一个常见词，看计数提示。
2. `n` 连续跳，确认计数跟着变。
3. 在折叠状态下按 `n`，确认自动展开了（`zv` 的作用）。
4. `N` 反向跳，确认计数和方向都对。
5. `Esc` 或 `:nohl` 清除高亮。

**验收**：搜索计数准确，跳转时折叠会自动展开。

## 注意事项

- **计数来自当前 buffer**，不是全项目。全项目搜索用 picker 或 quickfix。
- **与 which-key 不冲突**，但 `n` 被改造过，`:verbose nmap n` 可看来源。
- **虚拟文本需要 Neovim 0.10+**，更老版本会退化。
- 搜索高亮与 `hlsearch` 设置联动。
