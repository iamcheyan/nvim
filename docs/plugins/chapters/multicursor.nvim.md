# multicursor.nvim

> 公开插件 · [回到插件目录](../PLUGINS.md)

## 它解决什么问题

「把这 8 处的字段名一起改掉」这类活，逐处改既慢又容易漏。
multicursor 把光标同时放在多个位置，一次编辑作用于全部位置。

**这份配置只有一个多光标插件**（`vim-visual-multi` 已移除），
所以不存在两套插件抢键的问题。

## 在当前配置里怎么用

### VS Code 风格（推荐）

| 按键 | 模式 | 作用 |
|---|---|---|
| `Ctrl+n` | n / x | 添加下一个匹配 |
| `Ctrl+Shift+n` | n / x | 选中当前词/选区的**全部**匹配 |
| `Alt+d` / `Alt+Shift+d` | n / x | 跳过下一个 / 上一个匹配 |
| `<leader>mn` / `<leader>mN` | n / x | 添加下一个 / 上一个匹配 |
| `Esc` | 有光标时 | 清除所有光标 |

只在普通和可视模式绑定，所以**插入模式的 `Ctrl+n` 仍是补全**。`Ctrl+d` 仍是半页下滚。

### 按行加光标

| 按键 | 作用 |
|---|---|
| `<leader><up>` / `<leader><down>` | 跳过上一行 / 下一行再加光标。普通上下箭头保持移动 |
| `ga` + motion | 按动作加，`gaip` 给段落每行一个光标 |
| `<leader>A` | 对齐各光标的列。`<leader>a` 是数字加 1 |
| `<leader>gv` | 误清除后恢复光标集合。打开差异用 `<leader>gd` |
| `<leader>mq` | 暂停 / 恢复其它光标。`<C-q>` 是视觉块 |
| `<left>` / `<right>` | 切换主光标 |
| `<leader>x` | 删除主光标 |
| `Ctrl+左键` | 鼠标加/删光标 |

### 心智模型

执行一条命令时，它在每个光标处各跑一次。

所以光标必须落在**语义相同**的位置。`fP` 让每个光标各自跳到本行的 `P`，
正因为位置语义一致，同一条命令才有意义。

## 动手练习

1. 写四行相同的 `foo`，光标在第一个上，按两次 `Ctrl+n`：只选中前两个。
2. `Esc` 清除，回到第一个 `foo`，按 `Ctrl+Shift+n`：选中全部四个。
3. 改名为 `bar`，`Esc` 退出，确认四处都变了。
4. 在某个段落中间按 `gaip`，确认段落每行一个光标。
5. 用 `Alt+d` 跳过其中一个匹配后再改名，确认被跳过的没变。

**验收**：能区分「逐个加」「全加」「跳过」三种操作。

## 注意事项

- **`Alt+d` 跳过匹配**。`Ctrl+d` 是半页下滚。
- **`<leader>mq` 是暂停而不是关闭**。暂停时其它光标冻结，主光标可单独移动。`<C-q>` 进入视觉块。
- **`Esc` 一次清空**。改完想核对结果时别急着按。
- **`ga` 是操作符**，所以 `gaip`、`gaw` 都成立。
- 大范围光标可能影响性能，几千处时改用替换工具（grug-far）。
