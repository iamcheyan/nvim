# smart-paste.nvim

> 私有插件 · [回到插件目录](../PLUGINS.md)

## 它解决什么问题

从浏览器或文档复制一段代码粘进编辑器，缩进通常是错的：整块贴着第 0 列，
或者带着源文档的缩进。手动补缩进要一行一行来。

smart-paste 在粘贴时**保留块内的相对缩进，但把第一行对齐到当前光标位置**。

## 在当前配置里怎么用

| 按键 | 场景 |
|---|---|
| `p` / `P` | 内部寄存器粘贴（受智能处理） |
| `<leader>p` | 系统剪贴板块粘贴 |
| `<C-v>` | 块粘贴（普通/插入/可视模式） |

配置区分了三种来源，每种单独处理：

1. **内部 yank**（Vim 寄存器）
2. **系统剪贴板**
3. **终端 bracketed paste**

### 核心洞察

字符级 yank **不包含行首空白**。所以粘贴时必须记住「原来缺了多少空格」，
而不能从内层行的缩进去猜。配置的注释写得很清楚，这也是它的实现依据。

## 动手练习

1. 复制一个缩进的 `IF` 块（4 行），光标放到某个 `IF` 同级位置，按 `p`。
2. 确认块内相对缩进保持，第一行对齐到光标。
3. 从浏览器复制一段无缩进的代码，光标放到 Area B（第 12 列），粘贴。
4. 观察它是否从第 12 列开始。
5. 对比：用 `:set paste` 后粘贴，看差别。

**验收**：粘贴后相对缩进正确，第一行落在光标所在列的层级。

## 注意事项

- **`<C-v>` 被粘贴占用**，视觉块模式因此没有默认入口。
  想块选需要另找键或临时 `:normal! <C-v>`。
- **不要用 `:set paste`**，它会关掉所有自动行为，包括 smart-paste。
- **首行缩进依赖来源**。如果源文本本身没有缩进，只能按 0 处理。
- **大段粘贴会慢一两秒**，因为要逐行处理缩进。
