# indent-blankline.nvim

> 公开插件 · [回到插件目录](../PLUGINS.md)

## 它解决什么问题

深层嵌套的代码靠缩进判断层级，缩进线把「这一行属于哪一层」画出来。
对 Python、YAML、Lua 这类缩进敏感的语言价值最大。

## 在当前配置里怎么用

| 按键 | 作用 |
|---|---|
| `<leader>ug` | 开关缩进参考线 |

开关是全局的（`Toggle Indent Guides`），不需要逐文件设置。

### 与 COBOL 的关系

COBOL 固定格式**不靠缩进表达结构**，靠列位置。所以在 COBOL buffer 里
缩进线意义不大，配置对 COBOL 会禁用通用缩进线（`disable_indent_guide`），
改由 `cobol.nvim` 画列标尺。这是两类完全不同的视觉辅助。

## 动手练习

1. 打开一个多层嵌套的 Lua 或 Python 文件，观察缩进线。
2. `<leader>ug` 关闭，确认线消失。
3. 再按一次打开。
4. 打开一个 COBOL 文件，确认显示的是**列标尺**而不是缩进线。
5. 在一个只有单层缩进的文件里确认不会画出多余线条。

**验收**：普通语言有缩进线，COBOL 有列标尺，两者不叠加。

## 注意事项

- **不要用粗背景色块**。配置禁用了 colorcolumn 类的背景块，只用细线，
  避免遮挡文字。
- **在 COBOL 里被禁用是设计**，列规则由 cobol.nvim 的标尺负责。
- 缩进线宽度跟随 `shiftwidth`，改缩进设置会一起变。
- 某些终端下线条字符可能显示为方块，需要 Nerd Font。
