# grapple.nvim

> 公开插件 · [回到插件目录](../PLUGINS.md)

## 它解决什么问题

一次改动往往集中在几个文件之间来回跳：控制器、模型、测试。
`Ctrl-o` 只能沿历史一步步退，书签插件又常常按全局保存，切分支后指向错文件。Grapple 是「文件标签」：给文件打标签，标签按作用域保存，默认按 git 分支，切分支看到的是该分支自己的标签。

## 在当前配置里怎么用

| 按键 | 作用 |
|---|---|
| `<leader>ja` | 给当前文件加标签（再按一次取消） |
| `<leader>jt` | 打开标签列表窗口 |
| `<leader>js` | 打开作用域列表 |

也可以用命令 `:Grapple toggle`、`:Grapple toggle_tags`、`:Grapple toggle_scopes`。标签按 `scope = "git_branch"` 保存，切分支后自动切换集合。

## 动手练习

1. 打开一个项目里的文件，`<leader>ja` 打标签。
2. 再打开两个文件，同样打标签。
3. `<leader>jt` 打开标签列表，确认三个文件都在。
4. `<leader>js` 查看作用域，确认当前是 git 分支作用域。

**验收**：标签列表包含刚打的文件；切换分支后列表变成该分支自己的。

## 注意

- 标签保存在插件状态目录，不属于仓库文件，不会进提交。
- 分支删除后，该分支的标签仍占空间，可用 `:Grapple prune` 清理。
