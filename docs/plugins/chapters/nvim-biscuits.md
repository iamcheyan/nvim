# nvim-biscuits

> 公开插件 · [回到插件目录](../PLUGINS.md)

## 它解决什么问题

看一段很长的函数时，结尾的 `}` 或 `end` 不说明它是谁的结尾。Biscuits 在行尾用虚拟文本补上「这一行所属的块以什么结束」，长结构里不用再往上翻找对应的开头。

## 在当前配置里怎么用

默认随光标停留显示（`CursorHold` / `CursorHoldI`）：

| 按键 | 作用 |
|---|---|
| `<leader>uB` | 显示/隐藏这些虚拟文本 |

配置要点：

- `cursor_line_only = true`：只在光标所在行显示，避免满屏虚拟文本。
- `max_biscuit_length = 40`：超过 40 个字符的结尾文本截断。
- `default_separator = "  "`：虚拟文本与代码之间的分隔符。

## 动手练习

1. 打开一个嵌套较深的 Lua 或 Python 文件。
2. 把光标放在内层某行，停顿一下，确认行尾出现所属块的结尾提示。
3. 移到其它层，确认提示随之变化。
4. `<leader>uB` 关闭，确认提示消失；再按一次打开。

**验收**：只在当前行出现提示，内容对应该行所属的结构；开关即时生效。

## 注意

- 依赖 Treesitter；没有解析器时不会显示。
- 虚拟文本不写入文件，复制行内容时不会带上它。
