# vim-matchup

> 公开插件 · [回到插件目录](../PLUGINS.md)

## 它解决什么问题

原生 `%` 只能在单个括号之间跳，遇到 `if ... end`、`{% if %} ... {% endif %}`、HTML 标签这类成对关键字就无能为力。Matchup 用 Treesitter 和词法规则扩展了 `%`：在成对的构造之间跳转，还能把它们当文本对象选中和替换。

## 在当前配置里怎么用

| 按键 | 作用 |
|---|---|
| `%` | 在成对构造之间跳转（已支持关键字和标签，不只是括号） |
| `g%` | 反向匹配（从内层往外跳） |
| `i%` / `a%` | 选中当前成对结构的内容 / 连同边界 |

括号高亮由 Matchup 接管：

| 命令 | 作用 |
|---|---|
| `<leader>uM` | 启用括号高亮（`:DoMatchParen`） |
| `<leader>uN` | 停用括号高亮（`:NoMatchParen`） |

配置里设了 `matchup_surround_enabled = 1` 和 `matchup_transmute_enabled = 1`，前者让 `c%`/`d%` 之类直接作用在整对结构上，后者支持 `c%x` 这类「替换为另一种成对符号」的操作。

## 动手练习

1. 打开一个 Lua 文件，把光标放在 `function` 上，按 `%`，确认跳到对应的 `end`。
2. 在括号内按 `%`，确认仍按原生方式在括号间跳。
3. 在函数名上按 `d%`，确认整段结构被删除（可先 `u` 撤回）。
4. `<leader>uN` 确认括号高亮消失，`<leader>uM` 恢复。

**验收**：`%` 能匹配关键字结构；`i%`/`a%` 能选中整段。

## 注意

- 和 `rainbow-delimiters` 是不同职责：一个负责跳转与选中，一个负责着色，可以共存。
- 超大文件里括号高亮可能有开销，必要时用 `:NoMatchParen` 关掉。
