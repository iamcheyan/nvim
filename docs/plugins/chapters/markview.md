# markview.nvim

> 公开插件 · [回到插件目录](../PLUGINS.md)

## 它解决什么问题

编辑 Markdown 时你面对的是源码，但想看的是排版。markview 直接在缓冲区里
把标题、列表、表格、代码块渲染出样式，**不改源文件**。

## 在当前配置里怎么用

| 按键 | 作用 |
|---|---|
| `<leader>um` | 开关当前 buffer 的预览 |

加载时机是打开对应 filetype 时：`markdown`、`markdown.mdx`、`quarto`、`rmd`。
配置里明确写了为什么不用 `lazy = false`——那会让 `ft` 字段失效。

### 光标所在行保持源码

这是它能用的关键：光标停留的行显示原始 Markdown，方便继续编辑；
其它行显示渲染样式。所以你始终能看到自己正在改什么。

## 动手练习

1. 打开一个 `.md` 文件，观察标题和列表已经被渲染。
2. 把光标移到某个标题行，确认该行变回源码显示。
3. 修改标题文字，确认渲染实时更新。
4. `<leader>um` 关闭预览，确认变成纯源码视图。
5. 再按一次打开。

**验收**：预览与编辑可以无缝切换，光标行始终可编辑。

## 注意事项

- **预览不改文件**。用 `git diff` 确认过：开关预览不产生任何写入。
- **表格渲染需要正确分隔行**。缺 `|---|` 时表格不会渲染成表格。
- **和图片粘贴联动**。配置有专门的 Markdown 图片归档逻辑，
  见 [Markdown 图片指南](../guides/markdown-images.html)。
- **在 SSH 里图片可能不显示**，取决于终端能力。
