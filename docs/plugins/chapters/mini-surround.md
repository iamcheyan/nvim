# mini.surround

> 公开插件 · [回到插件目录](../PLUGINS.md)

## 它解决什么问题

给一个词加引号、把 `(` 改成 `[`、删掉外层括号——手动是「移到开头插入、
移到结尾插入」四次操作。mini.surround 变成「三个字母 + 一个符号」。

## 在当前配置里怎么用

| 按键 | 作用 |
|---|---|
| `gsa` | 添加包围符号 |
| `gsd` | 删除包围符号 |
| `gsr` | 替换包围符号 |
| `gsf` / `gsF` | 向前 / 向后查找包围符号 |
| `gsh` | 高亮当前所在的包围 |
| `gsn` | 更新搜索行数（默认 20 行） |

### 常见用法

| 输入 | 结果 |
|---|---|
| `gsa"` | 给当前词加双引号 |
| `gsa)` | 加圆括号（自动配成一对） |
| `gsr([` | 把 `(` 换成 `[` |
| `gsd"` | 删掉最近的一对引号 |
| `gsdb` | 删除最近的一对，任意类型 |

### 视觉模式

先 `V` 选中几行再 `gsa)`，每行都会被加上括号。
这是批量给代码块加缩进/括号的常用手法。

## 动手练习

1. 在一个词上按 `gsa"`，确认两侧加了引号。
2. `gsr"` 后输入 `'`，把双引号换成单引号。
3. `gsd'` 删掉它。
4. `V` 选三行，`gsa)`，确认每行都加了括号。
5. 在括号嵌套处按 `gsh`，看它高亮哪一层。

**验收**：添加、替换、删除三种操作都能在词和整行两个粒度上工作。

## 注意事项

- **`gs` 前缀固定**，后面跟操作字母，再跟目标符号。
- **`gsd` 删的是「最近的」一对**，嵌套时容易删错层，用 `gsh` 先确认。
- **搜索范围默认 20 行**。包围符号在更远处时先 `gsn` 加大范围。
- 自定义包围文本（多字符）支持有限，日常用单字符最稳。
