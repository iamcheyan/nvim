# mini.surround

> 公开插件 · [回到插件目录](../PLUGINS.md)

## 它解决什么问题

快速给文本添加包围符号，或删除、替换已有的引号、括号和标签。

## 在当前配置里怎么用

所有操作使用 `gs` 前缀：`gsa` 添加，`gsd` 删除，`gsr` 替换，`gsf` / `gsF` 向右/向左查找包围符号，`gsh` 高亮当前包围范围。添加时先按对象选择范围，再输入目标符号；例如 `gsaiw)` 给当前单词加括号，`gsaiw"` 给当前单词加双引号。`gsd` 后输入要删除的符号，如 `gsd)` 删除一层括号。

## 动手练习

在可丢弃的练习文件写 `hello`，按 `gsaiw)` 得到 `(hello)`；再用 `gsr)'` 把括号换成单引号；最后按 `gsd'` 删除引号。可用 `u` 逐步撤销。

## 注意事项

本配置把默认 `sa/sd/sr` 改成 `gsa/gsd/gsr`，与 which-key 的 `gs` 包围操作分组一致。添加动作后输入目标符号，范围可用 Vim 文本对象（如 `iw`、`i"`、`af`）。

## 查快捷键和帮助

运行 `:help mini.surround` 查看完整动作和自定义符号。用 `:verbose nmap gsa` 查看最终映射。
