# vim-illuminate

> 公开插件 · [回到插件目录](../PLUGINS.md)

## 它解决什么问题

读一段代码时，同一个变量或函数在哪些地方被用过，靠眼睛扫很慢。Illuminate 用 LSP 或 Treesitter 的结果，把光标下单词的其它出现位置统一高亮，并可以在它们之间跳转。

它和 `nvim-hlslens` 不是一回事：hlslens 显示的是**搜索结果**的位置，Illuminate 显示的是**光标所在词**的其它引用。

## 在当前配置里怎么用

| 按键 | 作用 |
|---|---|
| `]r` | 跳到下一个引用（到达末尾后回绕） |
| `[r` | 跳到上一个引用 |

高亮本身没有按键，光标移动后自动更新；`delay = 200` 表示停顿 200 毫秒才重新计算，避免移动时光标闪烁。

超过 4000 行的文件不启用（`large_file_cutoff`），启动页、文件树、Trouble、quickfix 和 Lazy 窗口也不启用（`filetypes_denylist`）。

## 动手练习

1. 打开一个 LSP 已就绪的文件，把光标放在一个变量名上。
2. 确认其它出现位置同时被高亮。
3. 按 `]r`，确认光标跳到下一个引用；按 `[r` 回到上一个。
4. 打开一个超过 4000 行的文件，确认不再自动高亮（避免卡顿）。

**验收**：引用位置被高亮且能用 `]r`/`[r` 循环跳转；大文件不卡。

## 注意

- 高亮依赖 LSP 或 Treesitter；两者都没有时不会有结果。
- 如果只想临时看，不用插件也可以 `:set hlsearch` 后搜索，但不会自动跟随光标。
