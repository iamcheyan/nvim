# symbol-usage.nvim

> 公开插件 · [回到插件目录](../PLUGINS.md)

## 它解决什么问题

想知道一个函数被引用了多少次、有没有实现，通常要打开 Trouble 或手动搜。这个插件把这些计数直接写在声明行的行尾：引用数、定义数、实现数一目了然。

## 在当前配置里怎么用

在 LSP 就绪的缓冲区里自动显示，不需要按键：

- `vt_position = "end_of_line"`：虚拟文本放在行尾。
- `disable.filetypes`：markdown、yaml、sh、Trouble、quickfix 不显示。
- `request_pending_text = "…"`：等语言服务器返回时先显示省略号。

## 动手练习

1. 打开一个 LSP 已就绪的项目文件，找到函数或类的声明行。
2. 确认行尾出现引用/定义/实现的计数。
3. 在另一个文件里调用该函数，保存后确认计数增加。
4. 打开一个 markdown 文件，确认不显示（已列入禁用列表）。

**验收**：计数出现在声明行行尾，并随引用变化更新；禁用文件类型不显示。

## 注意

- 需要支持对应请求的语言服务器；不是所有服务器都能给出引用计数。
- 计数是虚拟文本，不影响文件内容，也不会被复制。
